# Current requirements and proposals

Documents in this directory describe agreed work that is not implemented yet. They are not part of the current Scene Engine
contract or release tuple. Until a proposal is implemented, the binding behavior remains the one documented by the current
technical documents linked from the repository README.

There are currently no open proposals in this directory.

Implementation must update the affected current contracts, release tuple, public types and tests in the same change. Moving a
document out of this list, or changing its status, does not by itself make the behavior current.
